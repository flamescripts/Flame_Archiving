# Flame_Archiving
Various scripts to encourage and assist in making frequent Flame Archives.

### [Flame After Session Archiver](https://github.com/flamescripts/Flame_Archiving/tree/main/Flame_After_Session_Archiver_Plus) (Use Me!)

A utility to make it a little easier to archive your Flame project after a session. The project is flagged directly from within Flame and archived after Flame exits, instead of trying to guess the most recently used project like the legacy version. Supports Normal, Compact, and Omitted archives and can run automatically or prompt for the archive type after Flame exits. Tested with current Flame releases, work in progress, for guidance.  Upcoming functionality.  Automated archive uploads to Flow Production Tracking/Other WIP.

### [Flame After Session Archiver](https://github.com/flamescripts/Flame_Archiving/tree/main/Flame_After_Session_Archiver_legacy) (Legacy - For use with Flame 2025 and older.)

A utility intended to provide you with one less excuse not to archive after your Flame session.  Designed to assist in archiving projects for Autodesk Flame and will archive the most recent utilized project.  This script is configured to archive projects upon exiting Flame and offers options for various types of archiving: Normal, Compact, or Omitted. It can be executed automatically or manually. Tested in 2025, work in progress.

### [Flame Project Archive Assist Tool](https://github.com/flamescripts/Flame_Archiving/tree/main/Flame_Project_Archive_Assist_Tool)

A simple script that grabs the project listing and goes through each one and asks if it should be archived.  Not extensively tested, works for the use case it was intended for.  Has not been tested in recent releases, for guidance.

### [Flame Basic Nightly Archive](https://github.com/flamescripts/Flame_Archiving/tree/main/Flame_Basic_Nightly_Archive)

A very simple script to set a project and path to be archived.  Can be added to a cron job for after hours archival.  Checks if Flame is running and runs an archive.  Has not been tested in recent releases, for guidance.
